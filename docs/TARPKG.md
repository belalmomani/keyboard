# صيغة حزم الأدوات `.tarpkg` (الإصدار 1 — المراحل 3 و4)

الحزمة ملف **zip** بامتداد `.tarpkg`، وفي جذره ملف `manifest.json` إلزامي. باقي الملفات اختيارية
(`interface/` `runtime/` `documentation/` `tests/` `licenses/` ...) وتُفك كما هي في مجلد خاص بالأداة.

## manifest.json

| الحقل | إلزامي | الوصف |
|---|---|---|
| `id` | نعم | معرّف فريد: 2–32 حرفاً، إنجليزية صغيرة وأرقام وشرطة، يبدأ بحرف. هو ما يُكتب بعد `Run`. |
| `name` | نعم | اسم العرض (حتى 60 حرفاً) |
| `developer` | نعم | اسم المطوّر |
| `version` | نعم | Semantic Versioning مثل `1.2.0` |
| `description` | لا | حتى 500 حرف |
| `platforms` | نعم | مثل `["windows"]` — يجب أن يتضمن النظام الحالي |
| `kind` | نعم | المدعوم الآن: `command` |
| `engine` | لا | المدعوم الآن: `shell` (الافتراضي) |
| `dependencies` | لا | معرّفات أدوات أخرى يجب أن تكون مثبّتة ومفعّلة |
| `sdkVersion` | لا | إصدار SDK المطلوب (محجوز للمرحلة 5) |
| `minAppVersion` | لا | أدنى إصدار من Terminal AR |
| `permissions` | نعم | الصلاحيات المعلنة. يجب أن تتضمن `process.run` لنوع `command` |
| `signature` | لا | غير مستخدم؛ التوقيع الفعلي في الملف `signature/signature.json` (انظر أدناه) |
| `actions` | نعم | من 1 إلى 20 إجراءً |

### الصلاحيات المعروفة
`system.read` `files.read` `files.write` `files.delete` `network` `process.run` `services.manage`
`system.sensitive` `elevated`

> في المرحلة 4 تُفرض الصلاحيات على مستوى **قرار التشغيل** في النواة (Rust): كل صلاحية معلنة تحتاج منحاً صريحاً من المستخدم،
> وأي أمر يحتاج صلاحية لم تُعلن يُرفض التثبيت. هذا ليس عزلاً ديناميكياً — انظر `SECURITY.md` و`ISOLATION.md`.

### الإجراء (action)
حقلان اختياريان (v0.5.1): `mode` = `"run"` (الافتراضي، ينفَّذ مباشرة) أو `"insert"` (يُدرج الأمر في الطرفية دون Enter ليعدّله المستخدم، ويقبل أمراً واحداً فقط)، و`confirm` = `true` لطلب تأكيد قبل كل تشغيل.

```json
{ "id": "greet", "title": "عنوان بالعربية", "description": "اختياري",
  "shell": "powershell", "steps": ["Write-Output 'hi'", "whoami"] }
```
- `shell`: `powershell` أو `cmd` أو `any` (يعمل في الجلسة الحالية أياً كانت).
- `steps`: أسطر تُرسل بالترتيب إلى جلسة الطرفية الحقيقية. كل خطوة سطر واحد بلا محارف تحكم، حتى 2000 حرف.

## قواعد التثبيت
- حجم الحزمة ≤ 20MB، وعدد الملفات ≤ 500، والحجم بعد الفك ≤ 100MB، و`manifest.json` ≤ 256KB.
- تُرفض المسارات الخارجة عن مجلد الأداة (`..`)، والمسارات المطلقة، والأسماء التي فيها `:`، والروابط الرمزية.
- الإصدار الأعلى يحدّث الأداة، والمساوي أو الأدنى يُرفض (لا رجوع للخلف).
- لا يمكن استبدال أداة مدمجة بحزمة محلية.
- يُخزَّن SHA-256 للحزمة، وتُحفظ حالة التفعيل عبر التحديثات.
- لا تُزال أداة مطلوبة لدى أداة أخرى.

## الاستدعاء
في شريط الاستدعاء أعلى مساحة العمل: `Run <id>`. إن كان للأداة أكثر من إجراء تظهر قائمة اختيار،
ويمكن تحديد الإجراء مباشرة: `Run net ping`. الشريط خاص بـ Terminal AR ولا يعترض ما تكتبه في الطرفية.

## التوقيع (اختياري)
الحزمة الموقّعة تحوي `signature/signature.json`:
```json
{ "version": 1, "algorithm": "ed25519", "publicKey": "<base64 32B>", "signature": "<base64 64B>", "signer": "اسم اختياري" }
```
الحمولة الموقَّعة: `"TARPKG-SIG-V1\n"` ثم لكل ملف (عدا ملف التوقيع) مرتّباً بالمسار: `"<المسار>\t<sha256 hex>\n"`.
معرّف المفتاح = أول 16 خانة hex من sha256 للمفتاح العام. الأداة `tools/sign_tarpkg.py` توقّع وتتحقق.
الحالات: `unsigned` / `untrusted` (توقيع صحيح من مفتاح غير موثوق) / `trusted` / `builtin`.
توقيع صحيح لا يعني أن الحزمة آمنة؛ يعني أن محتواها لم يتغير منذ وقّعها صاحب ذلك المفتاح.

## ما ليس موجوداً بعد
العزل الديناميكي (دراسة فقط في `ISOLATION.md`)؛ محركات تشغيل غير `shell`، الواجهات الخاصة بالأدوات،
وSDK (المرحلة 5).
