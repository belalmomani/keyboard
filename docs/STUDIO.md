# Terminal AR Studio (المرحلة 5)

استوديو داخل التطبيق لتطوير أدوات `.tarpkg` (زر «الاستوديو» في الشريط العلوي). مصمم للكمبيوتر أولاً.

## الموجود فعلاً
- **مشاريع**: إنشاء من قالب، حذف، **استيراد مشروع خارجي** (zip أو .tarpkg؛ يُزال مجلد الجذر المشترك، ويُهمل `signature/` و`dist/` و`.git`، وتُرفض المسارات غير الآمنة).
- **ملفات**: شجرة، فتح/حفظ (حفظ تلقائي عند التبديل، Ctrl+S)، ملف/مجلد جديد، إعادة تسمية، حذف. كل المسارات تمر عبر `safe_rel` في Rust؛ `dist/` و`signature/` محجوزان للكتابة.
- **محرر**: Monaco (تلوين، تعدد أسطر) مع رجوع تلقائي إلى textarea إن فشل تحميله. **Monaco ليس VS Code كاملاً**: لا إضافات ولا IntelliSense لغوي كامل (worker المحرر الأساسي فقط).
- **إصلاح JSON** (v0.5.4): زر «ترتيب الملف» وزر «إصلاح تلقائي» في لوحة المشاكل يزيلان الفواصل الزائدة (خارج النصوص فقط) ويعيدان كتابة manifest.json في أسطر منظمة بترتيب مفاتيحه الأصلي.
- **تثبيت من كود** (تبويب «الأدوات»): الصق manifest.json مباشرة؛ يُصلح ويُفحص ويُثبَّت بكل فحوص التثبيت العادية.
- **زر «تعديل»** على بطاقة الأداة المثبتة: ينسخها إلى مشروع استوديو (إن لم يوجد مشروع بمعرّفها) ويفتحها. التعديل لا يغيّر المثبَّت حتى ترفع `version` وتضغط «تثبيت وتجربة».
- **الإصدار المثبّت بالفعل**: «تثبيت وتجربة» يعرض تشغيل النسخة المثبتة بدل الخطأ.
- **الإنشاء الموجّه** (v0.5.3): زر «إنشاء موجّه» — اسم الأداة + «ماذا تريد أن تفعل؟» + «ماذا تريد أن تظهر لك النتيجة؟». يختار المستخدم من **وصفات جاهزة** (فحص برنامج مثبت، منافذ، معلومات النظام، الأقراص، أكثر البرامج استهلاكاً، شبكة، ping، ملفات مجلد، أو أمر يكتبه بنفسه)، ويُسأل فقط عن مُدخلات الوصفة الناقصة، وتُعرض الأوامر المولَّدة قبل الإنشاء، وتُضاف الصلاحيات تلقائياً. **ليس ذكاءً اصطناعياً ولا فهماً لنص حر**: القائمة ثابتة (`src/recipes.ts`)، ويمكن إضافة وصفات جديدة.
- **نموذج الأداة** (v0.5.1): بدل كتابة JSON تملأ حقولاً (الاسم، المعرّف، الإجراءات، الأوامر سطراً بسطر، طريقة التشغيل: مباشرة أو إدراج في الطرفية، سؤال قبل التنفيذ). تحقق فوري تحت كل حقل، وإضافة الصلاحيات المطلوبة تلقائياً، ومعاينة لطريقة التشغيل. يُفتح تلقائياً بعد «مشروع جديد» أو بزر «نموذج الأداة».
- **لوحة المشاكل** (v0.5.1): كل خطأ يُعرض بمكانه (رقم السطر في manifest.json) وسبب وحلّ مقترح؛ الضغط عليه ينقلك للسطر، ويُمَيَّز السطر في المحرر. يعمل تلقائياً بعد حفظ manifest.json، وأخطاء JSON (فاصلة ناقصة، قوس) تظهر بسطرها. الأوامر التي تحتاج صلاحية غير معلنة تُحدَّد بسطرها.
- **تحقق**: manifest + قواعد التثبيت + الفحص الساكن (صلاحيات غير معلنة = خطأ).
- **اختبار**: تحقق ← فحص ← بناء ← تثبيت في قاعدة ومجلد مؤقتين. **لا تُنفَّذ أوامر الأداة** ولا تُمس الأدوات المثبتة.
- **بناء**: يكتب `dist/<id>-<version>.tarpkg` ويعرض SHA-256 ويحاول التنزيل.
- **تثبيت وتجربة**: يثبّت عبر مسار التثبيت الكامل (مع مراجعة الصلاحيات) ثم يشغّل الأداة في الطرفية الرئيسية؛ **سجل التنفيذ** يعرض سجل الأداة.
- **اعتماديات** و**صلاحيات**: تحرير manifest.json عبر واجهة. **SDK**: وثيقة الإصدار 1.
- **المحركات**: قائمة Runtime Adapters (shell فقط منفَّذ) + كشف node/python/git/rustc/pwsh على الجهاز (معلومة فقط).

## غير موجود (بصراحة)
- طرفية مدمجة داخل الاستوديو (تُستخدم الطرفية الرئيسية بعد «تثبيت وتجربة»).
- مصحّح أخطاء (debugger) حقيقي؛ المتاح سجل التنفيذ والاختبار الساكن.
- محركات wasm / python / node كـ adapters، ومصمم واجهات للأدوات.
- «إرسال للمراجعة»: زر معطّل حتى Marketplace (المرحلة 8).
- توقيع الحزم من الواجهة (يتم بـ `tools/sign_tarpkg.py`).
- Android: الاستوديو غير مخصص للهاتف؛ يُحدَّد المتاح في مرحلة Android.

## غير مجرَّب
لم يُبنَ شيء بعد. نقاط الخطر: حزمة monaco-editor مع Vite، والتنزيل عبر blob داخل WebView2، وCSP (أُضيف `worker-src blob:` و`font-src`).
